# Règles de développement

Pour chaque modification demandée :

1. Appliquer exactement la demande de l'utilisateur.
2. Ne pas prendre d'initiative hors du périmètre explicitement demandé : ne rien ajouter, supprimer, refactorer ni changer d'autre comportement sans demande. Si une ambiguïté empêche d'exécuter exactement la demande, demander une précision avant de décider.
3. Vérifier le code modifié.
4. Tester le comportement réel concerné.
5. Comparer le résultat aux exigences demandées.
6. Corriger et retester tant que le résultat ne correspond pas exactement.
7. Ne pas s'arrêter à une simple compilation réussie.

Une tâche n'est considérée comme terminée que lorsque l'implémentation et le comportement testé correspondent à la demande.
