# Règles de développement

Pour chaque modification demandée :

1. Appliquer exactement la demande de l'utilisateur.
2. Vérifier le code modifié.
3. Tester le comportement réel concerné.
4. Comparer le résultat aux exigences demandées.
5. Corriger et retester tant que le résultat ne correspond pas exactement.
6. Ne pas s'arrêter à une simple compilation réussie.

Une tâche n'est considérée comme terminée que lorsque l'implémentation et le comportement testé correspondent à la demande.
